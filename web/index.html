motion-platform-controller live demo

The controller core of this repository (mcue/, plain C) compiled to WebAssembly and running in your browser: classical washout cueing, workspace limiting, inverse and forward kinematics, the safety state machine and six cascaded leg servos at 500 Hz / 1 kHz, driving six simulated actuators. The same C runs in the Zephyr firmware and in the unit tests. Source
